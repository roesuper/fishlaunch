Everything happens around one Fortnite session.

Prepare the PC before the match, measure what happens during it, and put Windows back the way it was after. Each tool shows exactly what it does.

Game Mode

Windows steps aside while you play. Then steps back.

Game Mode turns on when Fortnite starts (you can switch that off), applies a short list of temporary changes, and undoes all of them the moment the game closes — even after a crash.

Smart Tune

A plan made for this PC, not a tweak pack.

Smart Tune scans your hardware, asks four questions, and picks from a library of 1,145 documented tweaks. Things you rely on — a Bluetooth controller, Discord voice, OBS — stay on.

FPS Doctor

Find out what is actually holding your FPS back.

FPS Doctor checks RAM channels, CPU boost, caps, V-Sync and drivers. With Fortnite running it measures whether the CPU or the graphics card is the limit — then tells you which fixes software can do and which need hardware.

Every session, with the FPS it really measured.

Game Mode logs each match: length, average FPS and 1% lows. Trends only compare sessions that used the same Fortnite settings, so a change of preset can't fake an improvement.

  • Average FPS and 1% lows per session
  • 30-second benchmark for before/after checks
  • Power plan duel that keeps the faster plan

Fortnite presets that check your PC first.

Pick a preset, a resolution and an FPS cap; FishyTweaks writes Fortnite's own settings file and keeps a copy of yours. Presets that could break the game on your hardware are switched off before you can choose them.

  • Balanced, Potato Pixel, Stretched and more
  • Resolution follows your monitor
  • Restore your original settings any time

Three steps from download to match.

No online account: your profile stays on this PC. Results depend on your hardware, so FishyTweaks measures instead of promising numbers.

  1. 01

    Download and install

    Get the installer from GitHub. It installs for your Windows user only and updates itself later — each update is signature-checked before it's installed.

    No admin needed to install.

  2. 02

    Analyze and configure

    Run FPS Doctor to see what limits your PC, let Smart Tune build a plan, and pick your Fortnite preset. Nothing changes until you press Apply.

    Admin once for system-wide changes: machine-level registry values, services, the custom power plan, DNS and the FPS meter.

  3. 03

    Apply and launch Fortnite

    Press Play with Game Mode, or just start Fortnite the usual way — Game Mode notices and turns on by itself. When you close the game, everything temporary goes back.

    Measured, not promised: check the result in Performance.

Never touches the game

Fortnite is found by its process name only. FishyTweaks never opens, reads or writes the game process, so there's nothing for Easy Anti-Cheat to see. It also never disables Windows security.

Where downloads come from

Installers are published on GitHub Releases. Updates are signed, and the app checks the signature with a key built into it before installing.

There's no paid Microsoft certificate yet, so Windows may show "unknown publisher" the first time.

Privacy

Profiles live only on your PC. No ads, no tracking. The app sends one anonymous count per day so we know how many people use it, and checks GitHub for updates.

Questions

Something else? Ask on the support page.

Windows says "unknown publisher". Is that normal?
Yes. A Microsoft code-signing certificate costs a few hundred dollars a year, which this free app doesn't have yet. Click More info → Run anyway. The installer comes straight from GitHub, and every update is checked against FishyTweaks' own signing key before your copy accepts it.
Smart App Control blocked it and there's no "Run anyway".
Smart App Control on Windows 11 only allows apps with a paid publisher certificate, and it can't be bypassed for one app. You can turn it off in Windows Security → App & browser control → Smart App Control. Windows only lets you turn it back on with a clean reinstall, so decide carefully.
Can it get me banned?
FishyTweaks never opens, reads or writes the Fortnite process and doesn't inject anything. It changes Windows settings and Fortnite's own settings file — the same file the in-game menu writes.
How much FPS will I gain?
It depends on your PC, and nobody can honestly promise a number. What moves FPS most is usually hardware setup (RAM in dual channel, XMP on), Fortnite's settings, and nothing fighting the game for the CPU. FPS Doctor shows which of these applies to you, and Performance shows the measured result.
How do I undo everything?
Open Settings in the app and press Undo everything. It reverts every tweak, the NVIDIA driver profile, the custom power plan and your Fortnite settings, then shows what it did. Smart Tune also makes a Windows restore point before each run.
How do updates work?
When the app starts it checks GitHub for a newer release. If there is one, you'll see an update banner; the download is signature-checked, installed and the app restarts in a few seconds. Nothing else downloads in the background.
I had FishLaunch. Is this the same app?
Yes. FishLaunch was renamed to FishyTweaks and now focuses on Fortnite. Your copy keeps updating itself from the same place.
