The installer is blocked

FishyTweaks doesn't have a paid Microsoft certificate yet. On the blue SmartScreen window, click More info → Run anyway. If Windows 11's Smart App Control blocks it with no Run anyway button, it can only be turned off in Windows Security → App & browser control → Smart App Control, and Windows only lets you turn it back on with a clean reinstall.

Game Mode didn't turn on

Open Game Mode in the app and check that Start with Fortnite is on. The FPS meter needs a one-time setup that Windows asks admin approval for; until then, Game Mode still works but can't show FPS.

Undo a change

  • One Smart Tune tweak: Smart Tune → History.
  • PC Tweaks: PC Tweaks → Revert everything.
  • Fortnite settings: Fortnite → Restore original config.
  • Everything: Settings → Undo everything. It also lists what it put back.

Smart Tune also makes a Windows restore point before each run, which you can use from Windows' System Restore if the app won't open.

Uninstall

Run Undo everything first, then remove FishyTweaks from Windows Settings → Apps → Installed apps.

Reporting a bug

Post on Discord with your app version (shown under the logo in the app), what you did, and what happened instead. A screenshot helps.
